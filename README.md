# 🥋 AI 바둑 마스터 (Baduk Master Web)

회원가입, 로그인, 4단계 AI 난이도 대국을 지원하는 풀스택 웹 바둑 애플리케이션입니다.

## ✨ 주요 기능

### 1. 🔐 회원가입 및 로그인 시스템
* **회원가입**: 아이디, 비밀번호, 닉네임 설정
* **로그인/로그아웃**: JWT 토큰 및 보안 쿠키 기반 인증
* **내 전적 관리**: 총 대국수, 승/패, 승률, 난이도별 상세 전적 및 최근 대국 기보 자동 기록

### 2. 🤖 4단계 인공지능 (AI) 난이도
* **쉬움 (Easy)**: 초보자/입문자용. 기초적인 단수 살리기/잡기를 하며 가끔 실수를 두어 쉽게 이길 수 있습니다.
* **보통 (Normal)**: 초중급자용. 자신의 단수 위기 방어, 상대 단수 즉시 포획, 귀/변 중심의 기초 포석 구사.
* **어려움 (Hard)**: 상급자용. 형태 감각(호구, 안형, 연결과 끊기, 급소 치중) 및 1~2수 앞읽기(Lookahead) 탐색.
* **최대 (Maximum)**: 최고 난이도. 몬테카를로 트리 탐색(MCTS Rollout) + 심층 정적 형세 평가 알고리즘을 결합한 강력한 AI.

### 3. 🎯 완전한 바둑 규칙 및 편의 기능
* **바둑판 크기 선택**: `19x19` (정규 대국), `13x13` (중급), `9x9` (빠른 속기)
* **돌 색상 선택**: 흑돌 (선착) / 백돌 (후착, 덤 6.5집 적용)
* **바둑 규칙 구현**: 활로(Liberties) 계산, 사석(Captures) 따내기, 자충수(착수 금지) 방지, 패(Ko) 룰 자동 적용
* **대국 편의 기능**:
  * 착수 포기 (Pass - 2회 연속 패스 시 자동 계가)
  * 기권 (Resign - 불계승/불계패 처리)
  * 무르기 (Undo)
  * 실시간 형세 판단 (집 계산 / 영토 시각화)
  * 착수 번호 (1, 2, 3...) 보기 ON/OFF
  * Web Audio API 기반의 현실감 넘치는 바둑돌 착수음 및 따내기 효과음

## 🚀 실행 방법

### 방법 1 (가장 쉬운 방법)
바둑 폴더 내의 **`실행하기.bat`** 파일을 더블 클릭하면 서버 구동과 함께 웹 브라우저가 자동으로 열립니다.

### 방법 2 (터미널 실행)
```bash
npm start
# 또는
node server.js
```
브라우저에서 **[http://localhost:3000](http://localhost:3000)** 으로 접속하세요.
